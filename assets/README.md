# GenerativeQC identity

Use **GenerativeQC**: uppercase G, Q, and C. The brand describes two complementary
forms of generation, not a claim that a generative model replaces validated
quantum-chemistry calculations.

## Meaning

- **Quantum chemistry:** the molecular/computational graph and continuous waves
  connect molecular structure, wavefunctions, and scientific computation. The
  six nodes are an abstract mark, not a specific molecule or a plotted orbital.
- **AI-assisted creation:** one seed branches into several wave-like paths,
  suggesting exploration and construction. In this project, coding agents help
  develop implementations, tests, and documentation under human scientific goals
  and review; the mark does not imply AI-generated energies without validation.
- **Compiler generation:** the curves become ordered parallel strokes ending in
  an output/code chevron. This represents the progression from scientific
  expressions and intermediate representations to specialized CPU/CUDA kernels.
  The open right side makes this a transformation, rather than a static molecule.

The cyan-to-violet transition follows that transformation. The visual connection
between these elements matters more than assigning a separate meaning to each
color. This is a conceptual identity, not an architecture diagram.

## Assets

| File | Use |
| --- | --- |
| [generativeqc-logo.svg](generativeqc-logo.svg) | Horizontal lockup on light backgrounds. |
| [generativeqc-logo-dark.svg](generativeqc-logo-dark.svg) | Horizontal lockup on dark backgrounds. |
| [generativeqc-icon.svg](generativeqc-icon.svg) | Standalone symbol and documentation favicon. |

The SVG files are the editable artwork sources. All visible lettering is drawn
as paths; there are no embedded bitmaps, font files, scripts, or external assets.
Each SVG includes a title and description. The horizontal assets have the same
`1052 256` viewBox and transparent background; preserve their aspect ratio.
Use the symbol rather than squeezing the full wordmark into a square.

The README selects its light/dark variant with a `picture` element. Sphinx uses
the same files through its theme's light/dark logo configuration, without copies
under `docs/`. Keep the symbol geometry aligned across all three SVGs when editing.
For small contexts, prefer the symbol at 32 px or larger and inspect smaller
favicon sizes separately. Leave clear space around the mark and do not stretch it.

## Typography and provenance

The wordmark is outlined from Inter Display Medium / SemiBold, version 4.001,
by the [Inter project](https://rsms.me/inter/). Inter is distributed under the
[SIL Open Font License](https://openfontlicense.org/); the
[OFL design-use FAQ](https://openfontlicense.org/ofl-faq/) covers logo artwork.
No font software is bundled or required to display these assets.

The emblem is an editable vector adaptation of the molecular-wave concept,
with branching paths and structured output added to communicate both meanings
of generation. It is intentionally not an embedded raster or an automatic
bitmap trace. Project artwork follows the repository license.
