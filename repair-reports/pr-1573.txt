## Implementation

Connect the **actual ordinary stationary CUDA driver** to the existing prepared Direct shell derivative facade. This is not another unused provider interface.

- Add a token-checked snapshot ABI returning separate full-range J and K gradient vectors from the current resident KS density and existing prepared Direct owner.
- Keep scientific coefficients, spin normalization, shell topology, density/Schwarz screening, bounded queues and derivative recurrence in the existing native provider. No functional-name selector or duplicate integral mathematics is introduced.
- Seed the compact contracted gradients into a freshly reset stationary source arena and retain the existing compiler-generated final device reduction.
- Skip migrated Coulomb/exchange sources **before** constructing their rank-four public-AO task domains. Semilocal plans skip J; global hybrids skip J and K.
- Keep one-electron, Pulay, nuclear and semilocal geometry sources unchanged, with source-by-source publication preserved.
- Report the selected native/fallback route explicitly; reconcile descriptor work after removing migrated ERI sources. Old AO counts remain logical capacity, not executed native shell work.

This targets PBE/r2SCAN J and PBE0/B3LYP J/K through the same operator-based boundary, including both spin conventions.

## Compatibility, lifetime and resources

Both producer and seed ABIs are checked before provider execution. Missing ABI or explicit native NOT_IMPLEMENTED retains the bounded AO capability fallback; stale state, allocation, CUDA and numerical failures never silently re-execute a fallback. ECP and RSH/nonlocal compositions retain their existing routes.

The seed operation accepts a finite complete source array exactly once after reset and before any numerical source work. It drains partially submitted transfers on failure before the caller's host arrays can disappear.

No second Direct owner or new persistent matrix is allocated. Compact O(Natom) staging reuses the existing conservative transient host allowance. **This is not a zero-transfer join:** the current native facade downloads compact J/K gradients, and seeding uploads the source array and drains once. Those costs are explicit; eliminating that compact round trip is separate lifetime work.

Native generated/screened/compacted/executed shell counts are unavailable from this ABI and remain null. A zero `public_ao_quartets_submitted` proves the migrated Python task domain was bypassed, not that native integral work is zero.
