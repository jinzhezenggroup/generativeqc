## What changes
- generate a dedicated CPU Hamiltonian control VJP that publishes only `stationarity` and `orbital_rhs`, not the dense `bar_g[N^4]` output;
- use that pruned VJP for intermediate correlation/canonicalization control response;
- fold the same-space canonical-orbital Fock seeds into the existing `foo/fvv` parameter cotangents, with a TensorIR parity test against the independent full-Fock VJP;
- accumulate the physical Z seed directly into `fov`;
- execute the complete Hamiltonian derivative VJP only once, after all CC/(T)/canonicalization/Z seeds have been assembled;
- explicitly release control/curvature workspaces before the final derivative VJP.

## Why this slice
Before this change, the force owner materialized complete dense ERI cotangents for correlation, denominator, canonicalization, orbital-Z, and reference contributions separately, then added them. Those intermediate `N^4` outputs are unnecessary because only orbital stationarity/RHS is needed before the final nuclear derivative.

This PR removes those intermediate retained `N^4` cotangents. The remaining dense frontier is now narrower and explicit: the raw `g[N^4]` input and the **single final** `bar_g[N^4]` publication.

## Next #1575 slice
Replace that last final `bar_g` publication with block-addressed ERI cotangent production and immediate shell-derivative contraction; then replace the raw full-MO `g` owner / dense orbital JVP with provider-backed matrix-free actions.
