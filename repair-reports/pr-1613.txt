## Summary

Continue the WB97M-V CUDA stationary residency stack on top of #1612 by removing per-tile partition-weight uploads.

#1581 already retains the exact CUDA-generated molecular-grid points and partition weights. After #1612 borrows resident point coordinates, the stationary geometry consumers still copied `state.grid.weights[begin:end]` from host into a private tile buffer for both semilocal and nonlocal geometry.

This stack:
- borrows the exact resident partition-weight slice from the native molecular-grid owner;
- adds semilocal and nonlocal stationary enqueue variants that accept device weights directly;
- uploads only the still-host-owned raw atomic measure for each tile;
- retains host weights only for the opt-in detailed profiling fallback;
- records `grid_weight_source = exact-native-resident-grid` and `grid_weight_h2d_bytes = 0`.

## Correctness boundary

The existing geometry kernel is unchanged. Only the source pointer for the already-materialized partition weights changes.

The new ABIs retain:
- exact atom-major owner-offset validation from #1611;
- existing borrowed GridTask stream/lifetime rules;
- existing nonlocal seed stride/offset validation;
- unchanged raw atomic measure and moving-grid/Becke response;
- unchanged synchronous detailed-profile fallback.

Source-level guards require the resident-weight paths to contain no `upload(*p, p->weights, ...)` call and to keep the raw-measure upload explicit.
