# Decision: compose CLI CPU hybrid D4 resource contracts

Status: implemented
Date: 2026-11-25

## Problem

The installed CLI executed named PBE0 and B3LYP D4(BJ-EEQ-ATM) through the
native CPU named owner but refused those methods in `resources` and consequently
under `run --host-bytes`. A shared carrier is not evidence of an identical
electronic program, correction, or allocation contract.

## Decision

Admit the exact compiled hybrid D4 identities and their aliases. Compose the
existing full-range CPU host inventory with the native D4 fleet inventory;
use the same receipt for dry-run and pre-execution admission. Restrict this
increment to all-electron Direct FP64; keep derivative, fitted, packed and ECP
contexts subject to their separate qualification. This is a modeled numeric
envelope, not a Direct allocation lease, process RSS bound or new force method.

Refs #2227.
