# Decision: Compose the cold CPU saddle host envelope around the electronic lease

Status: implemented
Date: 2026-11-24

The energy/force batch is still live when occupied orbitals are exported and
the two roots are compared. Its lease cannot stand in for the corrector's
panels, the caller outputs, or the original normalized system handles and
their coefficients. The CLI removes a fixed two-frame envelope from the
effective cap before preparing the native electronic lease. An initial
shape-only cross-overlap query reserves room for the next moved trial. The
derivative and physical export scratch execute serially; the same workspace
reservation covers the larger of the two. Reserving only that floor dropped
the optional integral matrix schedule on level-0 NH₃, increasing curvature
primitive work from 269,730 to 3,236,760. Instead, let the native lease select
spare capacity up to the caller's derivative cap before constructing a batch.
The exact minimum still admits the bounded low-memory schedule. Harmonic
analysis runs only after the corrector returns and is admitted separately.

Do not use the first frame's smaller root receipt as the aggregate cap for
subsequent trials. Do not admit warm seed restore until it accounts for its
copied source system and source-metric validation, in addition to capture and
retained seed payloads. Cold Fock damping has a separate preparation owner;
the combined force/Hessian lease currently excludes ECP. Unbudgeted replay
keeps those existing policies.
