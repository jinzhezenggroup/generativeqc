# Decision: qualify the actual selector, grid and native resource owner

Status: implemented
Date: 2026-11-15

## Problem

The expanded #2227 R1 campaign exposed three different failures that must not
be conflated with missing force equations. PBE-D3 strings failed before native
preparation although their MethodIR interface already worked. An independent
r2SCAN oracle silently replaced its prescribed grid. Older r2SCAN-3c assertions
expected host gCP and Python primitive pages after those owners had migrated.

## Decision

Project a single D3 or D4 correction away only while selecting the electronic
carrier. Preserve the full MethodIR as correction identity and native admission
authority. Rename the private projection helper and migrate all consumers
directly; do not retain a D4-only compatibility alias or relax the native
source-completeness/property gate. String/MethodIR parity exercises both spins,
backends and Direct/DF with cold/warm/moved and energy-only execution.

Configure the independent PySCF radius policy **before** installing the native
grid's coordinates and weights. PySCF Grids resets built arrays when that
policy changes. The semilocal oracle now verifies that neither independent
SCF nor its analytic gradient replaces those arrays. Keep the existing
scientific tolerances; changing the grid or relaxing the gate would hide an
oracle error rather than fix production numerics.

Test the real native resource owner. Native integral ownership legitimately
elides Python AO primitive pages; a one-record Python-page cap cannot reject
pages that do not exist. Check zero exported pages and a real one-byte native
device budget refusal instead. Require CUDA gCP provenance and prohibit a
Python force fallback at the public prepared endpoint.

## Evidence and rejected alternatives

The D3 entry-point regression has 40 backend/spin/approximation cases. The four
independent default-grid r2SCAN-3c CUDA analytic comparisons passed after the
oracle fix with maximum energy/force errors of 4.84e-13 / 1.14e-10 atomic units.
These are scoped receipts, not universal grid/convergence qualifications.

The first paired endpoint campaign is retained as failed/incomplete. It has
actual D3 constructor failures, an allocation timeout and measured ratios over
1.05; concurrent qualification is a diagnosis to investigate, not permission to
relabel those ratios as noise. Its work auditor also cross-joined different
sample ages with equal moved-geometry parity. MGGA_X_LTA's identical repeated
history then looked like changed work. The replacement auditor compares work
at identical sample indices and still compares observables over all matching
geometries. Adversarial receipts must fail for true same-sample work changes,
stale identity, missing execution, force errors and timing regressions.

Keep parent/candidate D3 timing on the common MethodIR interface, resolving it
inside the measured cold endpoint. Qualify repaired string entry separately.
Do not manufacture parent support or change samples, controls or gates to get a
green performance result. Keep all source, binary, runner and auditor identities
with each campaign, and isolate timing from other self-owned GPU jobs.

## Invariants and revisit conditions

No force equation, precision default, physical domain or energy-only capacity
promise changes here. No blanket force bit or production PySCF fallback is
introduced. Automatic energy registrations remain distinct from molecular-force
qualification; compiled composed CUDA providers require their own registration
entries even when their atomic ingredients are already packaged. Revisit when
that packaging contract or the independent oracle's grid API changes.
