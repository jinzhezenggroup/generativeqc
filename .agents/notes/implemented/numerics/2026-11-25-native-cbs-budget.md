# Native CBS allowance planning

The CBS convergence query owns the Standard default, L1 amplification and
component allocation. It consumes the rounded extrapolation receipt, so it
cannot silently rederive weights that differ from those used for observables.
Clients still declare which basis identity, if any, is shared with the MP2
correction subtraction. Deduplicate only that MP2 coefficient before taking
magnitudes; distinct methods on the same basis still contribute independently.

A single compensated sum was considered and rejected. With cardinals 28/52,
correlation exponent `7.860377502539633e-164`, HF exponent
`6.250054175082996e-155`, and a shared low correction, it rounds the norm one
ULP below the previous `math.fsum` result. The six-element fixed expansion
preserves the midpoint decision without carrying a second Python policy or
allocating reduction scratch. Contract tests compare against legacy summation
and stopping limits across all correction roles and rounding regimes.

No allowance, an omitted RMS limit, and a positive allowance that selects
strict convergence are separate states. In particular, reject division that
underflows a requested RMS allowance to zero rather than treating the request
as an omission. This is a stopping plan, not a measured error certificate;
backend admission, unrestricted strict convergence, and force response
qualification do not change.
