# Decision: share canonical ERI factors across frozen-matrix directions

Status: implemented; component-qualified, complete-endpoint qualification pending
Date: 2026-11-13

## Problem

The source-bound factorized-first-source attempt completed first preparation,
then exhausted its unchanged 1,800-second complete-endpoint cap inside frozen
integral preparation. Density projection itself completed in 0.269355 ms. That
attempt supplies phase evidence but no completed raw Hessian or modes. See
`2026-11-13-factorized-host-first-sources.md` in this directory; its sealed archive

The matrix schedule previously reevaluated the same canonical factor algebra for
three to nine physical right directions per primitive. Sharing geometry alone
does not share the pair, Coulomb, Gaussian-prefactor or product factors.

## Decision

Add a build-only CPU full-range s--f matrix lowering. Reuse `_pair_expansion`,
`build_coulomb_derivative_algebra`, `_eri_differentiate`, and the scalar Graph/CSE
emitter. Product rules are generated by differentiating the scalar product;
there is no native handwritten derivative recurrence or second scientific
algebra. Each factor carries its ordered raw second partials. Center D remains
fixed, producing value + nine A/B/C partials + 81 mixed partials in 91 fields.
All mixed entries are emitted directly, not manufactured by copying a transpose.

The native matrix consumer applies the existing compensated physical-owner
scatter to each left/right mathematical incidence. Equal numeric coordinates
never identify owners. All-identical-owner symmetry-unique quartets retain the
existing scalar-only operation. Ordinary mixed-pair/column providers remain
available; first sources, S/T/V, ECP, XC, D3 and response mathematics do not change.
No molecular ERI derivative tensor is retained: the fixed primitive jet is
stack-local, while the existing bounded coordinate Hessian staging is unchanged.

## Work and safety invariants

Keep the conservative existing physical-right-direction admission plan and all
work/storage/time caps. Do not multiply an actual matrix-call counter by the
old number of calls. `eri_matrix_primitives` is a subset of actual second-order
calls; the value/first/mixed partition still sums to actual primitive calls.
These derivative orders have different costs. Neither fewer calls nor isolated
leaf medians establish complete-endpoint performance.

Preserve public normalization and external radial scaling exactly once, every
ordered generated J/K weight incidence, signed RKS/UKS densities, immutable
snapshots, validation cadence, aliases, finite rejection, transactionality and
recovery. Preserve raw symmetry/response/reference gates and both public ECP
saddle guards. No oracle, finite difference, runtime compiler or different
functional/basis/ECP/grid enters production.

## Rejected alternatives

- Increasing caps or repeating the unchanged expensive endpoint is not a fix.
- Geometry-only reuse leaves the other factor work repeated; retain its measured
  comparison rather than treating it as equivalent sharing.
- New native derivative formulas, copied-transpose Hessian repair and relaxed
  scientific tolerances are invalid substitutes for canonical lowering.
- Reducing admission plans solely because one matrix call replaces several
  directional calls would conflate derivative-call count with semantic work.
