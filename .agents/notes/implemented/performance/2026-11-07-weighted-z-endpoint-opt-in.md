# Decision: separate default-off weighted-Z endpoint mode

Status: implemented opt-in linkage; endpoint qualification pending
Date: 2026-11-07

## Decision and invariant

The exact weighted-Z companion keeps the measured compiler arithmetic from
`69f8a1de154b64ba4c5b68ae034753a868e15007`. The local complete-queue decision
passed both classes' strict matrices, resources and ten balanced timing pairs.
Those results authorize an endpoint experiment, not a default or all30 claim.

`GENERATIVEQC_CUDA_HF_SHARED_RYS_WEIGHTED_Z=1` requires the independent existing
XY control to equal1. Absent/empty/0 preserve established behavior; any other
value is invalid before shape admission. Appending `WeightedZOn` preserves old
enum values and policy layout while its existing equality invalidates both
directions of plan/graph reuse. CUDA prepared identity records the exact control;
CPU identity does not depend on it.

A private typed header owns only the additive weighted capability and launch.
Registry availability is independent of XY and is intersected with enabled
incumbent coverage. RHF selects that variant's mask once, then all materialized
helper/wave/retry consumers use the frozen mode. Existing refusals and original
fallback occur before enqueue; a launch failure is returned without a second
incumbent launch. No public ABI, arena, task or `SharedRysXyPolicy` size changes.

Default/private and XY-only bodies retain their previous bytes. Weighted code
keeps its one-task bit guard, original seed/fill/HRR/scatter and fixed mapping.
No gather, warp-retirement, normalization factoring or new cache is included.

## Evidence and consequences

The retained local qualification had96 matrix predicates,56 exact guard controls,
zero sanitizer errors/spills, <=2KiB static shared and unchanged occupancy/local
limits. Complete saved-queue replay had24 full800² numerical gates and all20
paired ratios above1 (DPPP median1.14172, PPPP1.07523). These describe one sealed
queue per class on one H100, not removable endpoint time.

Only integration-specific parser, capability, ABI, resource identity and real
linked-dispatch checks are new here. The old54 reference arrays and scientific
qualification are carried forward. A separately reviewed same-owner native
incremental build may start only after all old WB consumers retire and their
source/native closure is sealed; normal dependencies decide actual work.

The first endpoint pilot has XY1 in both arms and varies only weighted0/1, with
original native/DIIS selectors0. Cold E+analytic force plus three matched warm
calls must preserve original settings/work and independent/strict E/F gates.
Each warm ratio must satisfy the existing5% bound. One cold pair is diagnostic;
production/default promotion and broader paired qualification remain separate.
