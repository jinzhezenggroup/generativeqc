# Decision: Batch raw auxiliary columns in spectral exchange response

Status: implemented and qualified on sampled A100 and RTX 5090 endpoints
Date: 2026-11-02

## Problem

The #2932 fitted long-range exchange candidate improves repeated cold Fock
applications but has an expensive force response on warm WB97M-V DF calls.
The truncated metric needs the original projected integrals `P_Q = C^T A_Q C`,
including components in discarded metric directions. Retained fitted factors
alone cannot reconstruct the inverse-square-root Frechet adjoint.

The spectral response previously requested one packed raw auxiliary column per
source call. For the README 96-atom def2-SVP/def2-SVP-JKFIT case this means
3616 raw source invocations, followed by 3616 separate occupied projections.
An older diagnostic 5090 trace attributed about 28.3 seconds to raw generation
within a 54.7-second LR force response. Those instrumented historical numbers
identify a target; they are not clean timing evidence for this candidate.

## Decision

Generate a bounded packed auxiliary panel in the already allocated derivative
weight buffer, then unpack each requested column into the separate AO slice
before projecting it. The raw projection phase ends before any derivative
weights are emitted. Both phases use the same stream. No new allocation,
retained tensor, density approximation, metric formula or GPU-model selection
is introduced.

The panel holds `tile * nbf * (nbf+1)/2` doubles, which fit in the existing
`tile * nbf^2` interval. It follows the final tile after budget reduction or
allocation retry, including tile one and a short tail. Cache state is local to
one response invocation; no contents survive warm replay or geometry changes.

Source invocations decrease to the number of panels, while raw integral values,
generated bytes and occupied-projection arithmetic remain unchanged. Trace
counters distinguish packed source panels from consumed raw slices. This is
batching of existing work, not elimination of the raw physical tensor's work.

## Invariants

- Preserve retained/discarded subspace motion and the stable inverse-root adjoint.
- Never alias the live packed input panel with the unpacked AO slice or `C^T A C`.
- Do not enlarge the existing response allocation or bypass its bounded fallback.
- Keep the current exact/mixed LR default and explicit fitted-LR/shell selection.
- Compare complete energy-plus-force endpoints with identical scientific inputs;
  label mixed DF, fitted DF and Direct separately.

## Validation

The new native test compares physical derivatives to independent host raw
integral derivatives for both Coulomb and erf operators, positive and negative
exchange seeds, tile one, ragged tails and repeated calls. The test supplies a
truncated metric and exact density-generating occupied coefficients without
borrowing a raw tensor or an SCF projection. Existing independent spectral
adjoint and g-auxiliary molecular tests remain required.

Development source receipts, build provenance and scheduler results are kept
under the ignored `.artifacts/wb97mv-spectral-panels-20261102/` directory.
The panel-only source identity is
`9e1d10a19f86ca2df78506a7f92405eeda537ca67032fc05125b6cd20f21be2a`,
compared with #2932 identity
`a53c7618fcd59b88693a693a08a36f7ad3bfa51969f6564b46561e95e04505fa`.
Both use DF full-range J/K, fitted long-range exchange and shell derivatives,
96 atoms, def2-SVP/def2-SVP-JKFIT, README default grids, one cold complete
energy/force endpoint and three warm frozen-density replays. These are
default-grid static-geometry measurements, not a general accuracy-qualified
ranking or a comparison against a master checkout.

The A100 cold difference is noise; batching alone does not establish a cold
improvement. Warm time decreases by 3.3% and 6.3%, respectively. Native Fock
counts remain 28 cold and one per warm call; grids and VV10 work are unchanged.
All cold/warm sample pairs against the original agree within `1.7e-10` maximum
force-component error. On A100, all sample pairs against stock GPU4PySCF DF
agree within `8.31e-10` hartree/atom and `2.36e-7` hartree/bohr, passing the
README observable gates without establishing grid-converged qualification.

The 64 independent native panel controls and 16 Python spectral/molecular
controls pass on both GPUs (LSF 224816 and Slurm 15689). The latter Slurm job
also reports zero compute-sanitizer memcheck errors. Forty-two host resource
budget/fallback tests pass.

A fresh matched A100 diagnostic job (224833) corrects the historical 5090
bottleneck estimate: LR raw generation decreases from 1.8222 to 0.8312 seconds,
while derivative contraction stays at 15.38 seconds. Raw source calls decrease
from 3616 to 57, generated bytes remain 8,542,322,688, and the response workspace
remains 2,207,609,600 bytes. The current automatic packed-single source does
not retain an additional raw tensor that this response could simply borrow.
The subsequent target is therefore long-range derivative lowering; see
[the Rys decision](2026-11-02-long-range-rys-derivatives.md).

## Revisit when

If source batching does not improve complete warm execution enough, measure
occupied projection and derivative contraction separately before changing
their batch sizes. A larger derivative panel must retain budget replanning;
cross-call raw reuse would require a separate immutable geometry/operator owner
and a charged capacity policy.
