# Decision: coefficient-keyed weighted-Z companion to shared XY

Status: implemented capability; device qualification and production selection pending
Date: 2026-11-07

## Problem and decision

The qualified DPPP/PPPP component owner shares unweighted XY tables but repeats
weighted Z for each retained component. A strict default-false schedule capability
shares only bit-identical weighted seeds: one fixed Cartesian alpha group for
PPPP, two for DPPP. A uniform task vote checks finite representative products and
every retained component's exact alpha bits, including signed zero. Refusal uses
the original XY arithmetic within the same shared lifetime before primitive work
or Fock publication. Small-live masks retain the incumbent private-axis policy.

The representatives use the original ordered four-coefficient expression.
Weighted seed, common TRR fill, HRR, root/primitive accumulation, screening and
canonical scatter retain their original placement. Producers remain unconditional
with respect to output masks; their Z writes join the existing publish/retire
barriers. The fixed SM90 96/192-thread mappings and all production selectors stay
unchanged. Typed serialization and artifact identity record the capability.

## Rejected alternatives and limits

Factoring alpha out of the weighted seed can introduce overflow, underflow and
rounding loss. Contracting VRR before HRR also changes primitive cancellation and
has no closed bounded incumbent fallback. Both remain outside this companion.
Terminal gather and PPPS warp retirement are separate rejected experiments.

The source inventory on existing sealed complete queues counted 95.6440% and
97.0615% fewer table fills and logical shared envelopes of 1152/1664 B. Counts are
not GPU timing or physical resource results. Private/shared compilation is not
assumed bitwise equivalent. Reuse the existing independent Cartesian arrays and
strict full-matrix/graph gates, then inspect actual resources before a separately
approved fixed saved-queue comparison. No production integration follows merely
from compiler/host checks.
