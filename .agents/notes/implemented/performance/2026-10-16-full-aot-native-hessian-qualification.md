# Decision: retain full-package endpoint evidence without promoting failed ratios

Status: implemented qualification and evidence policy; comparison not accepted
Date: 2026-10-16

## Problem and decision

A small selected-tile AOT package cannot qualify the practical full orbital-f /
auxiliary-g migration. Reusing its faster endpoint samples under a new source or
inventory identity would hide both build selection and runtime cost. Qualify the
complete linked package, retain complete process timings and preserve the common
matrix gate even when an independently energy-qualified native result disagrees
with the installed reference analytic Hessian.

## Complete-endpoint measurements

The same allocation then ran both engines sequentially, with one first-observed
sample and two interleaved artifact-primed fresh processes per engine/case.
Each process includes fresh SCF, the complete host Hessian and JSON publication.
Both engines had the same 600-second deadline. Grids were matched 8/4/8 with
moving Becke response and self-consistent VV10; no chemical grid-convergence
claim follows from this small workload.

| Case | Native raw median (s) | GPU4PySCF raw median (s) | Max matrix difference (Eh/Bohr²) |
| --- | ---: | ---: | ---: |
| H2 | 1.7680009955074638 | 5.473529880167916 | 9.326707032830672e-5 |
| Water | 15.514822122175246 | 10.857629530597478 | 0.001045670978818275 |

Both common full-matrix gates fail at unchanged atol=3e-6, rtol=0. All twelve
endpoints completed, but the comparator and consequently the Slurm command exit
with status 1. This is not an all-green job or an accepted speed comparison.
Qualified ratios remain null. Do not attribute differences from the earlier
selected-tile measurements to one isolated optimization without a matched A/B.

## Evidence retention

`benchmarks/results/wb97mv-hessian-native-full-20261016/` is published through the
shared validation/publication contract. It retains every matrix, sample, work
count, environment and binary/runner identity, the inventory recipe/hash and the
independent reference own-primal diagnostic plus its exact script. No external
archive or release is required. The reproduction script is provided but was not
independently replayed end to end.

To stay within the aggregate evidence budget, the older independent RHF Hessian
oracle `hessian-reference-180/qualification.json` is losslessly XZ-compressed.
Decompression is byte-identical to its original Git content, SHA256
`7ae33d89fd41f6d75e0e9c9245b28cd0bd3214cfa291af23b0245e042b38262f`.
No numerical evidence or acceptance gate is removed.

## Revisit when

The installed reference/adapter has an independently verified analytic/primal
consistency fix. Repeat the unchanged full-matrix gate and complete endpoint
measurements rather than substituting kernel timings or weakening tolerances.
