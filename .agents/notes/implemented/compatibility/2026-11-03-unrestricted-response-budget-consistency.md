# Decision: align unrestricted response admission with its executed providers

The fitted unrestricted method owner bypassed an older energy-only Fock helper
and inherited the generic derivative-order-one default. Make the active fitting
policy take the requested derivative order explicitly, and migrate the native
contract tests to that production owner instead of retaining an unused helper.
Both conventional and full-fitted energies use order zero; force requests retain
order one and the independently validated physical response.

Unrestricted CC force preflight must include the separate conventional-reference
graph for correlation-only fitting. Repeat complete admission after actual
fitted storage and CUDA reference capacity are known, before starting CC work.
The initial lower-bound check still rejects impossible requests before SCF.

The CUDA one-electron derivative provider uploads two AO weight matrices and
packed topology/pair inventories. Its capacity cannot always be the unrelated
fixed 8 MiB ERI recurrence allowance. Reserve system-dependent staging through
the shared checked post-HF capacity owner, include it in both UMP2/UCCSD endpoint
peaks, and pass that same finite reservation to execution. Do not pass arbitrary
unused endpoint headroom or hide extra staging outside reported capacity.
Provider out-of-memory status remains a resource refusal, not numerical failure.

The host regression includes a synthetic 1024-AO staging inventory without
executing that unphysical system. Existing independent small-system numerical,
inclusive-budget and failure-publication contracts remain the acceptance gates;
this budget-only change is not new GPU or large-domain scientific qualification.
