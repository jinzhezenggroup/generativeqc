# Require the selected CPU HF fleet inventory

The per-item HF host query bounds one phase of a local owner; it cannot prove
the composed fleet's retained topology and workspace lifetime. Previously an
older library could supply leaf sizes while Python supplied the rest of the
live fleet bound. A fleet with ECP could also take its workspace bound from
portable arithmetic even when the fleet query was present.

Require both the existing fleet inventory and any active ECP workspace query
on the selected CPU owner. The older leaf ABI remains useful for portable
comparison tests and other native consumers, but not as a runtime fallback.
Library-free dry runs retain the independent portable model. None of these
metadata receipts establish provider leases or process-wide memory coverage.
