## Decision

Use existing scalar TensorIR input/constant/add/multiply/divide/sqrt operations.
The ordered-history contract fixes phase, recurrence, chronological overlay,
finite-check and publication semantics. Its stage graph hashes and manifest are
part of its identity, rather than provenance-only annotations.

Add a bounded native-statement mode to the existing scalar C++ lowerer. It uses
ordinary TensorIR nodes, explicit native ordered sums and caller-owned checks.
Binary operation and square-root spellings are shared with the existing helper
emitter. It creates no second scalar expression tree or evaluator. The default
helper emitter retains its outputs.

Dot, Cholesky and seeded correction use common builders for both schedules.
Method adapters provide physical names and failure destinations. Native bodies
are not copied into separate CPU/CUDA string constants. Admission rejects graph
or schedule mutations before emission.

## Numerical invariants

- Preserve native compiler FMA policy; do not force fused/unfused arithmetic.
- CPU compact beta stride equals h; CUDA stride equals capacity.
- Dot order increases over packed components; coefficient weights are applied
  after the dot; diagonal regularization is added after the weighted overlap.
- Correction starts with the damped seed and subtracts each chronological term.
  Seed 1e16 with terms [1e16, 1] yields -1, while subtracting their sum yields 0.
- Factorization checks after inner folds, requires positive pivots, checks
  division results, and retains partial scratch writes on failure.
- Preserve CPU immediate failures and CUDA flag/break/phase-barrier behavior.
- No new history-capacity bound below native admission.

## Independent-review admission repair

The initial gate's read validator admitted hidden arithmetic/effects inside
parentheses, and arbitrary failure tuples could omit CUDA invalidation. These
were compiler-admission defects even though approved adapters preserved bytes.

Physical bindings now use a closed full-match name/member/index grammar. Index
arithmetic is limited to literals/names and integer address operators. Calls,
commas, casts, nested expressions and malformed suffixes are rejected. The two
CPU overlay accessors require explicit declarations and one identifier argument;
targets cannot call accessors. Every raw correction address/name field and dot
loop control is validated, not only scalar stage operands.

Failure effects are typed rather than executable text tuples. CPU dot failure
returns false; CPU correction returns its bound method status call. CUDA phases
must report an error and atomically invalidate their shared flag. The dot phase
adds break; correction continues to the existing phase barrier. Callers cannot
omit invalidation, supply an empty branch, or insert a thread-local return.
Error function/data/message choices remain method-owned. Approved adapter output
bytes and default scalar-helper behavior remain unchanged.

## Rejected alternatives

Separate pasted backend bodies, an independent scalar algebra, generic DIIS
replacement, summed correction, triangular Gram mirroring, LAPACK/BLAS/solver
promotion, changed finite-check locations and compiler contraction-policy
changes. None satisfies this source-preserving ownership migration.
